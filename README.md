## 📌 Featured Project

### Rune Archive — Anime & Manga Data Discovery Application

Rune Archive is a data-driven web application I developed as my senior Data Science project. It combines Python-based data collection and processing with an interactive JavaScript frontend.

The project collects anime and manga data through the AniList GraphQL API, processes and structures the data using Python and Pandas, and provides an interactive interface for discovering and organizing titles.

**Key features include:**
- Live title search
- Genre, format, status, score, year, and media-type filtering
- Multiple sorting options
- Detailed anime and manga information
- Similar-title recommendations
- Favorites and personal ratings
- Personal collection management
- Customizable user profile
- Responsive interface

**Technologies:** Python • Pandas • GraphQL • JavaScript • HTML • CSS • JSON
